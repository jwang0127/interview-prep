# 多威体育｜电商财务 BP

## 业务

越南运动鞋跨境电商，核心平台为 Lazada、TikTok Shop。链路：采购/生产 → 入仓 → 上架投放 → 下单 → 发货签收 → 售后 → 平台结算 → 跨境回款。

## 岗位要求

平台订单/账单/售后/物流/回款对账；按平台、店铺、SKU、品类分析贡献利润；跟踪投放 ROI、退货率、汇率、库存和现金；推动业务、供应链、仓库和财务闭环。

## 我的匹配

链接 [[05-案例库/19.8万返点漏记]]、[[05-案例库/600万美元逾期款追回]]。待补：Lazada/TikTok Shop 后台字段、越南税务和本地 ERP。

先讲对账方法，再确认公司当前平台合同、结算和税务口径；不要把会变化的平台规则说死。
