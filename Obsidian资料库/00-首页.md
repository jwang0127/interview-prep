# 王春元｜求职成长资料库

> 目标：把岗位要求转化为可学习、可练习、可证明的能力。

## 先看这里

- [[01-我的能力画像]]：我已经具备什么、证据在哪里、哪些地方要补齐。
- [[02-岗位地图]]：10 个岗位的业务场景、共性要求和岗位差异。
- [[03-技能地图]]：按“理解业务 → 算清利润 → 预测预算 → 推动决策 → 建立机制”组织。
- [[04-学习路线-90天]]：按周执行的成长路线。
- [[05-案例库/案例总览]]：面试中可复用的 STAR 证据。
- [[06-面试/面试题库与回答框架]]：把学习内容转成面试表达。
- [[07-复盘/面试复盘模板]]：每次面试后沉淀反馈。

## 当前定位

财务 BP / 经营分析候选人，优势集中在电商与市场业务、预算与滚动预测、ROI/毛利分析、应收账款风险和跨部门项目推进。首选方向是电商财务 BP、市场/营销财务 BP、经营分析；可延展到跨境电商、广告传媒、算力/科技和财务咨询。

## 使用方法

1. 每周从 [[04-学习路线-90天]] 选一个主题，产出一个可展示的模型或一页分析。
2. 每次面试前打开对应的 [[02-岗位地图]] 岗位笔记，补齐“业务等式”和反问问题。
3. 每个答案都链接到一个真实案例；没有真实证据的内容标记为“待验证/待补齐”。
4. 面试后填写 [[07-复盘/面试复盘模板]]，把新问题加入题库。
